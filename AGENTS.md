# KM Video AGENTS.md

## Git workflow

This project is in its early stage and nothing is published yet.

- Commit directly to `main`. Do not create feature branches or pull requests unless asked.
- Make small commits with clear messages, one logical change per commit.
- Push to `main` after committing so the work is backed up on GitHub.
- Pull before starting work in case changes were made elsewhere.

## Tools

- Higgsfield MCP is configured in `.cursor/mcp.json` for generating images, video and audio.
